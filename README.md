# ledgewayadvisory.com

Single-page marketing site for Ledgeway Advisory. Served as static files by Caddy.

| File | Live URL |
|---|---|
| index.html | https://ledgewayadvisory.com/ |
| brand/ledgeway-logo-2000.png | https://ledgewayadvisory.com/brand/ledgeway-logo-2000.png |

## Deploy

Copy the files to the server's site root, keeping the folder layout. Nothing to build.

## Note

The claude.ai artifact "Ledgeway Advisory" is an older draft. It is missing the
title, description, canonical and Open Graph tags that the live page has.
